# pbt
Python Basis Tool

A set of Python scripts for interacting with basis sets. Mostly translates between different formats used by electronic structure codes. Also has some visulaisation of exponents. Most of the scripts were written 10+ years ago, but it is made available for anyone who wants to use it.

## Installation
pbt is a series of Python scripts. Simply download from GitHub and they can be used with few dependencies. If you wish to use the scripts directly, such as the `molext2gbasis.py` script for converting between Molpro external basis set and the GBASIS format, you may want to add the main pbt directory to your $PYTHONPATH and the scripts directory to your $PATH.

## Running pbt
The current best way to run pbt is to use the scripts that convert between the different formats. These are found in the `scripts` directory. They should all have a basic usage output if you call the scripts without any arguments.
